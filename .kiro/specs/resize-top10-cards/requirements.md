# 需求文档

## 简介

调整管理员仪表板中右侧三个 TOP10 统计卡片(用户活跃 TOP10、节点使用 TOP10、存储使用 TOP10)的尺寸,使其与底部"告警监控"卡片的尺寸保持一致。

## 术语表

- **AdminDashboard**: 管理员仪表板组件,显示集群监控数据的大屏界面
- **TOP10 卡片**: 右侧列中显示排行榜数据的三个卡片组件
- **告警监控卡片**: 底部区域显示系统告警信息的卡片组件
- **db-card-rank**: TOP10 卡片使用的 CSS 类名
- **db-card-bottom**: 告警监控卡片使用的 CSS 类名

## 需求

### 需求 1

**用户故事:** 作为系统管理员,我希望 TOP10 统计卡片的尺寸更小且与告警监控卡片一致,以便在大屏上获得更平衡的视觉效果。

#### 验收标准

1. WHEN 管理员查看仪表板 THEN 系统应将三个 TOP10 卡片的高度调整为与告警监控卡片相同
2. WHEN 调整卡片尺寸后 THEN 系统应保持卡片内部内容的可读性和布局完整性
3. WHEN 卡片尺寸改变后 THEN 系统应确保图表组件正确响应新的容器尺寸
4. WHEN 在不同主题(浅色/深色/海洋)下查看 THEN 系统应保持一致的卡片尺寸和样式
5. WHEN 浏览器窗口调整大小时 THEN 系统应保持卡片的响应式布局
