# WebShell 快捷键使用指南

欢迎使用 ComputeNook WebShell！本指南将帮助您快速掌握键盘快捷键，提升工作效率。

## 🎯 快速上手

WebShell 的快捷键会根据您的操作系统自动适配：
- **Mac 用户**：使用 **⌘ (Command)** 键
- **Windows/Linux 用户**：使用 **Ctrl** 键

本文档中用 `⌘/Ctrl` 表示这个修饰键。

## 📋 常用快捷键

### Tab 管理（最常用）

| 操作 | 快捷键 | 说明 |
|-----|--------|------|
| 新建终端 | `⌘/Ctrl + T` | 打开连接窗口，选择节点 |
| 关闭终端 | `⌘/Ctrl + W` | 关闭当前终端标签 |
| 切换 Tab | `⌘/Ctrl + 1~9` | 快速切换到第 1-9 个终端 |
| 上一个 Tab | `⌘/Ctrl + [` 或 `←` | 切换到左边的终端 |
| 下一个 Tab | `⌘/Ctrl + ]` 或 `→` | 切换到右边的终端 |

### 终端操作

| 操作 | 快捷键 | 说明 |
|-----|--------|------|
| 清屏 | `⌘/Ctrl + K` | 清除终端所有输出 |
| 全屏 | `⌘/Ctrl + F` | 进入/退出全屏模式 |

### 设置

| 操作 | 快捷键 | 说明 |
|-----|--------|------|
| 终端设置 | `⌘/Ctrl + ,` | 字体、主题、光标等 |
| 密钥管理 | `⌘/Ctrl + Shift + K` | SSH 密钥上传/生成 |

## 💡 使用技巧

### 1. 快速切换多个终端
如果您同时连接了多个节点：
```
⌘/Ctrl + 1  →  切换到第1个终端（登录节点）
⌘/Ctrl + 2  →  切换到第2个终端（计算节点）
⌘/Ctrl + 3  →  切换到第3个终端（GPU节点）
```

### 2. 顺序浏览终端
使用 `⌘/Ctrl + [` 和 `⌘/Ctrl + ]` 可以像翻书一样浏览所有终端窗口。

### 3. 清理屏幕输出
当终端输出过多时，按 `⌘/Ctrl + K` 立即清屏，比输入 `clear` 命令更快！

### 4. 全屏专注模式
需要专注工作时，按 `⌘/Ctrl + F` 进入全屏，再按一次退出。

### 5. 快速打开设置
Mac 用户习惯的 `⌘ + ,` 快捷键也能用！快速调整终端外观。

## 🎨 个性化设置

按 `⌘/Ctrl + ,` 打开终端设置，您可以调整：

- **字体大小**：10px - 24px，适配不同显示器
- **配色方案**：
  - Dark（默认深色）
  - Light（浅色）
  - Monokai（经典编程主题）
  - Dracula（流行的暗黑主题）
  - Nord（清新的北欧风格）
- **光标闪烁**：开启/关闭光标闪烁效果

## 🔐 SSH 密钥管理

按 `⌘/Ctrl + Shift + K` 打开密钥管理，有两种方式：

### 方式一：自动生成（推荐）
1. 点击「自动生成」标签
2. 点击「一键生成密钥对」
3. 系统自动生成并部署到所有节点
4. 以后连接无需输入密码

### 方式二：手动上传
1. 点击「手动上传」标签
2. 选择您本地的私钥文件
3. 上传后即可使用密钥认证

## 📱 快捷键提示条

页面顶部有常驻的快捷键提示条（打开终端后显示）：

**Mac 上显示：**
```
⌘+1~9 切换Tab | ⌘+[/] 前后Tab | ⌘+T 新建 | ⌘+W 关闭 | ⌘+K 清屏 | ⌘+F 全屏 | ⌘+, 设置
```

**Windows/Linux 上显示：**
```
Ctrl+1~9 切换Tab | Ctrl+[/] 前后Tab | Ctrl+T 新建 | Ctrl+W 关闭 | Ctrl+K 清屏 | Ctrl+F 全屏 | Ctrl+, 设置
```

## 🔧 按钮提示

将鼠标悬停在工具栏按钮上，会显示对应的快捷键提示。

## ⚠️ 注意事项

1. **浏览器快捷键优先**
   - 部分快捷键可能与浏览器冲突
   - 例如：`Ctrl + T` 在某些浏览器中会先打开新标签页
   - 建议在全屏模式下使用以避免冲突

2. **终端内部快捷键**
   - `Ctrl + C`、`Ctrl + D` 等是发送给终端的
   - 不会被 WebShell 捕获
   - 正常使用即可

3. **Mac 特殊说明**
   - 使用 `Cmd` 键而不是 `Ctrl` 键
   - `Cmd + [/]` 切换 Tab 符合 Mac 习惯
   - `Cmd + ,` 打开设置也是 Mac 标准

## 🎓 实战示例

### 场景 1：同时监控多个节点
```
1. 按 ⌘/Ctrl + T，连接到登录节点
2. 再按 ⌘/Ctrl + T，连接到计算节点1
3. 再按 ⌘/Ctrl + T，连接到计算节点2
4. 按 ⌘/Ctrl + 1/2/3 快速切换查看
```

### 场景 2：提交作业后监控日志
```
1. 在终端1提交作业：sbatch job.sh
2. 按 ⌘/Ctrl + T 新建终端2
3. 在终端2监控：tail -f slurm-xxx.out
4. 按 ⌘/Ctrl + 1/2 来回切换查看
5. 输出过多时按 ⌘/Ctrl + K 清屏
```

### 场景 3：全屏专注编辑
```
1. 按 ⌘/Ctrl + F 进入全屏
2. 打开 vim 或其他编辑器工作
3. 完成后按 ⌘/Ctrl + F 退出全屏
```
